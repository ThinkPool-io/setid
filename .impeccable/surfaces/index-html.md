# SetID site (home + set view)

Scope: index.html + app.js, the whole static site. Home is Persuade, set view is Operate.
Audience: casual listeners asking "track ID @ time" and DJs digging for tracks and setlists.

## Direction contract

THESIS: Tonhalle. A Swiss concert poster discipline on black: grid, one grotesque, rhythm. Refuses the category's dark-dashboard default (cards, neon accent, glow).
OWN-WORLD: Black #0E0E0E, bone #F2F0EA, three greys, vermilion #E8452C as the single signal; amber only for low-confidence state. Schibsted Grotesk only, tabular figures. No cards, no boxes, no dividers as containers; rank is brightness.
STORY: The visitor sees the comment-section question at poster scale, pastes a link, watches the worker listen, then reads a set as rhythm and copies an answer.
FIRST VIEWPORT: 12-col grid. Status lines in cols 1-3; headline "Track ID @ 47:12?" at up to 160px in cols 4-12, promise below, underline paste field with vermilion "Identify the set" button. Below: the latest set drawn as rhythm, one line per identified track.
FORM: Swiss concert poster (Tonhalle), position 6 of the ordered list; seed key 3b62832f.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
